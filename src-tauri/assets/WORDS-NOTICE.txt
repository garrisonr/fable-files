words-en.txt.gz — the File Auditor's bundled English word list.

Provenance: derived from SCOWL (Spell Checker Oriented Word Lists),
en_US list, version 2020.12.07, as distributed by the Debian
"wamerican" package (/usr/share/dict/american-english). The bundled
file is a normalized derivative: lowercased, split on non-letters,
pure a-z entries of length >= 2, deduplicated and sorted
(73,581 words). The application ships this list itself and never
reads a system dictionary at runtime.
