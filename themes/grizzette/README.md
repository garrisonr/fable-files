# Grizzette

The built-in example theme for Fable Files — the peach-paper /
chocolate-ink / orange-red look from the Gazette, Save-A-Tron, and the
shopping list, shipped as a portable theme package.

Install: drop this folder into the app's themes directory (or use the theme
gallery's import-from-file). One-click rollback is supported: the previously
active theme is kept until you confirm the new one.

Token reference: see `docs/THEME_FORMAT.md`. Contrast report for every text
pair is generated by `theme_contrast_report` — Grizzette ships contrast-clean
(verified by the `grizzette_passes_contrast` test in `ufm-themes`).
