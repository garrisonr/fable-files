# Fable Light

The warm-paper light theme for Fable Files — parchment surfaces, warm-ink
text, one calm action blue. Ships contrast-clean against the full
pair matrix in `docs/THEME_FORMAT.md` (text and status roles at WCAG AA
4.5:1, `focus_ring` at 3:1), verified by the ufm-themes contrast gate
(`every_shipped_theme_is_contrast_clean`, in the cargo test suite).

Install: drop this folder into the app's themes directory (or use the theme
gallery's import-from-file). Token reference: see `docs/THEME_FORMAT.md`.
