# Fable Dark

The true-dark neutral theme for Fable Files — near-black surfaces, neutral
grays, one luminous action blue. Ships contrast-clean: every text pair
(`text`/`surface`, `text_muted`/`surface`, `accent_text`/`accent`,
`text`/`content_canvas`) reaches WCAG AA 4.5:1, verified by
`scripts/contrast_check.py`.

Install: drop this folder into the app's themes directory (or use the theme
gallery's import-from-file). Token reference: see `docs/THEME_FORMAT.md`.
